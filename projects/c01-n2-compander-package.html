03

How the package works

A nitrogen compander for shipyard service: three compressor stages and one expander stage share one integral gearbox, taking nitrogen from 7.4 to 35.3 bar(a).

Water-cooled intercoolers and an after cooler sit after the stages, the expander returns power to the gear train, tandem dry gas seals sit on every shaft end, and an anti-surge valve protects the compressor at low flow.

05

Engineering Scope

04.1

Lubrication System

Designed the 3D lube-oil system and associated equipment; participated in equipment selection including strainers, filters, coolers and AOP pump with senior engineers.

04.2

Seal Gas

Created the complete 3D seal-gas system and participated in seal-gas panel planning in line with API 692 requirements.

04.3

Package Structure

Created the 3D base frame, foundation drawings and package tie-in/interface arrangement, including load considerations for lifting and transportation.

04.4

Cooling water

Water is the cooling medium for the whole package: a supply and return header serves the intercoolers, the after cooler (AC), the lube-oil cooler and the motor cooler.

04.5

Deliverables

GA drawings, BOQ/MTO, manufacturing drawing review, customer revisions and technical support through manufacturing and FAT.

06

Key design challenges

05.1

Compact package for shipyard service

Fitting three compressor stages, the expander, lube-oil and seal-gas systems and water-cooled coolers onto one base frame sized for a shipyard installation under ABS rules.

05.2

Lifting, transport and base-frame loads

Designing the base frame for static equipment and piping loads plus lifting and transport cases, so the package could be moved as one unit.

05.3

Seal-gas and lube-oil integration

Routing the API 692 seal-gas lines and the API 614 lube-oil system around the compander core while keeping them short, drainable and accessible.

05.4

Cooling-water distribution

Distributing one cooling-water supply and return to the intercoolers, after cooler, oil cooler and motor cooler with isolation on every branch.

09

Engineering Takeaway

Piping, equipment, drawings and manufacturing interfaces were all coordinated from the one 3D model. The hard part was fitting several auxiliary systems around the compander and still ending up with a package the shop could build. Because the package was built for shipyard service, the design also had to meet ABS (American Bureau of Shipping) rules alongside API 617, 614, 692 and ASME B31.3.
